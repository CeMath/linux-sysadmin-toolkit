## bash-examples

Reference scripts with well-commented Bash examples.

### Scripts

**`ejemplos_en_bash.sh`**

Practical examples of string manipulation in Bash:

- String length, substrings, and indexing
- Simple and global replacement (sed-style)
- Uppercase / lowercase conversion
- Indirect variable referencing (nameref)
- Interactive menu with `select`
- Useful tricks with `awk`, `bc`, and `paste`
